## ✅ ВИКОНАНІ ЗАВДАННЯ

### 1. Діаграма варіантів використання (Use Case Diagram)
📄 **Файл**: `usecase_csharp.puml` (формат PlantUML)

**Містить**:
- **4 актори**: Application, Глядач (Viewer), Автор (Author), Модератор (Moderator)
- **12 варіантів використання**: реєстрація, публікація, планування, запуск чату, підписка, перегляд, коментування, модерація, блокування, видалення, апеляція, статистика
- **Залежності**: include, extend відносини між варіантами

**Ключова особливість**: На місці Main класу використано Application як доменний актор, який керує всією системою.

---

### 2. Діаграма класів (Class Diagram)
📄 **Файл**: `class_csharp.mmd` (формат Mermaid)

**Містить**:
- **7 основних класів**:
  - `Application` - точка входу програми
  - `PremierSystem` - система управління (агрегує користувачів та контент)
  - `User` - абстрактний базовий клас
  - `Viewer` - конкретна реалізація для глядачів
  - `Author` - конкретна реалізація для авторів
  - `Moderator` - конкретна реалізація для модераторів
  - `Content` - клас контенту

- **2 інтерфейси**:
  - `IEngageable` - для Viewer (Subscribe, WatchContent, CommentOnContent)
  - `IModeratable` - для Moderator (BlockSpam, ModerateChat, DeleteInappropriateComment)

- **40+ методів** з параметрами та типами повернення
- **Явні взаємозв'язки**: наслідування, реалізація інтерфейсів, агрегація (List<User>, List<Content>)

**Особливість**: Повна архітектура проекту, включаючи абстрактні класи та інтерфейси, які в вихідних діаграмах були відсутні.

---

### 3. Діаграма послідовності (Sequence Diagram)
📄 **Файл**: `sequence_csharp.mmd` (формат Mermaid)

**Містить**:
- **6 учасників**: Application, PremierSystem, Viewer, Author, Moderator, Content
- **7 сцен виконання програми**:
  1. Реєстрація користувачів
  2. Публікація контенту
  3. Планування прем'єри
  4. Взаємодія глядачів
  5. Модерація контенту
  6. Демонстрація поліморфізму
  7. Апеляція та статистика

- **20+ операцій** з точною послідовністю викликів методів
- **Кольорові блоки** для кожної сцени для наочності

**Особливість**: Точно відображає логіку виконання програми з Program.Main().

---

### 4. Діаграма станів системи (State Diagram)
📄 **Файл**: `state_csharp.mmd` (формат Mermaid)

**Містить**:
- **15 станів системи** з явними переходами:
  - Ініціалізація → РеєстраціяКористувачів → ПублікаціяКонтенту → ПланюванняПрем'єри
  - → ЗапускЧату → ВзаємодіяГлядачів → Підписка → ПереглядВідео → КоментуванняВідео
  - → МодеріацаКонтенту → БлокуванняСпаму → ВидаленняКоментарів → ДемонстраціяПоліморфізму
  - → Апеляція → СтатистикаСистеми

- **Лінійний потік** виконання програми (замість циклічного у вихідній)
- **Явна відповідність** до методів у Program.Main()
