## 🔗 Матриця Відповідностей: C# ↔ UML

```
┌──────────────────┬──────────────────────────────┬─────────────────┐
│ C# Елемент       │ UML Елемент                  │ Де знаходится   │
├──────────────────┼──────────────────────────────┼─────────────────┤
│ Program          │ Application (actor)          │ usecase, seq    │
│ PremierSystem    │ System (class)               │ class, seq      │
│ User             │ Abstract class               │ class           │
│ Viewer           │ Concrete class, actor        │ class, usecase  │
│ Author           │ Concrete class, actor        │ class, usecase  │
│ Moderator        │ Concrete class, actor        │ class, usecase  │
│ Content          │ Concrete class               │ class, seq      │
│ IEngageable      │ Interface                    │ class           │
│ IModeratable     │ Interface                    │ class           │
└──────────────────┴──────────────────────────────┴─────────────────┘

Ключ: usecase=діаграма варіантів, class=діаграма класів, seq=послідовність
```
