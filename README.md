# Об'єктно-орієнтований проект: Система управління прем'єрами (C#)

## Опис проекту

Імітаційний прототип системи управління відеопрем'єрами, розроблений на мові C# з використанням принципів об'єктно-орієнтованого програмування.

### Основні ролі системи:
- **Viewer (Глядач)** - користувач, який переглядає контент і залишає коментарі
- **Author (Автор)** - користувач, який планує прем'єри та опублікує контент
- **Moderator (Модератор)** - користувач, який модерує контент та чат
- **Content** - відеоконтент з метаданими

## Архітектура і принципи ООП

Проект демонструє наступні ключові концепції ООП:

### 1. **Наслідування (Inheritance)**
- Клас `User` - базовий клас для всіх типів користувачів
- Класи `Viewer`, `Author`, `Moderator` успадковують `User`

### 2. **Інкапсуляція (Encapsulation)**
- Приватні атрибути класів з захистом доступу
- Публічні методи (getters/setters) для управління станом об'єктів

### 3. **Поліморфізм (Polymorphism)**
- Реалізація інтерфейсів `Engageable` та `Moderatable`
- Перевизначення абстрактного методу `performAction()`

### 2. **Інтерфейси (Interfaces)**
- Інтерфейс `IEngageable` - визначає поведінку для взаємодії з контентом
- Інтерфейс `IModeratable` - визначає поведінку для модерації

### 5. **Агрегація (Aggregation)**
- Клас `PremierSystem` керує колекціями користувачів та контенту

## Вимоги

- .NET SDK 8.0 або вищої версії
- Bash або аналогічний shell

## Компіляція

Для компіляції проекту використовуйте команду:

```bash
dotnet build
```

Для запуску програми виконайте:

```bash
dotnet run
```

Або компіляція та запуск разом (однією командою):

```bash
dotnet run
```

Після компіляції виконавчий файл буде розташований у директорії `bin/Debug/net8.0/`.

## Приклад виконання

При запуску програма демонструє:

1. **Реєстрацію користувачів** - додавання глядачів, автора та модератора
2. **Публікацію контенту** - створення та опублікування відеоматеріалів
3. **Планування прем'єри** - автор планує прем'єру та запускає чат
4. **Взаємодію глядачів** - перегляд контенту та коментування
5. **Модерацію контенту** - блокування спаму та видалення неприпустимих коментарів
6. **Демонстрацію поліморфізму** - виклик методів через базовий клас User
7. **Апеляцію на модеративне рішення** - подання скарги автором
8. **Статистику системи** - вивід всієї інформації про користувачів та контент

## Перехід з Java на C#

Основні відмінності у реалізації:

### Синтаксис:
- **Java**: `public class`, **C#**: `public class` (практично одне і те саме)
- **Java**: `package com.premiere;`, **C#**: `namespace Premiere;`
- **Java**: `String`, **C#**: `string` (мале літери)
- **Java**: `ArrayList<T>`, **C#**: `List<T>` (більш просто)

### Властивості та методи:
- **Java**: getter/setter методи (`getName()`, `setName()`)
- **C#**: Property syntax з `{ get; set; }`
- **Java**: абстрактні методи, **C#**: з ключовим словом `abstract`

### Інтерфейси:
- **Java**: `interface Engageable`, **C#**: `interface IEngageable` (з префіксом I за конвенцією)

### Точка входу:
- **Java**: `public static void main(String[] args)`
- **C#**: `static void Main(string[] args)` у класі `Program`

### Вивід на консоль:
- **Java**: `System.out.println()`
- **C#**: `Console.WriteLine()`

### Перевірка типу:
- **Java**: `instanceof`
- **C#**: `is` оператор
