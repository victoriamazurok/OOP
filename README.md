# Відеоплатформа "YouTube Premier"

Це іммітаційний проєкт, що демонструє систему управління прем'єрами для відео-контенту. Проєкт реалізує механізми реєстрації користувачів, публікації контенту, взаємодії глядачів з контентом, модерації чату, а також статистику використання.

## Призначення проєкту

Проєкт дозволяє:
- Реєструвати користувачів різних ролей (глядачі, автори, модератори).
- Публікувати контент (відео).
- Взаємодіяти з контентом (підписка, перегляд, коментарі).
- Модерувати контент (блокування спаму, модерація чату).
- Переглядати статистику користувачів та контенту.

## Шлях до Java-файлів

Основні Java-файли знаходяться в директорії `src/main/java/com/videoplatform`:
- `Main.java` — головний клас для запуску проєкту.
- `User.java` — абстрактний клас для користувачів.
- `Viewer.java` — клас для ролі глядача.
- `Author.java` — клас для ролі автора.
- `Moderator.java` — клас для ролі модератора.
- `Content.java` — клас для контенту (відео).
- `PremierSystem.java` — клас для управління системою прем'єр.
- `VideoplatformModule.java` — модуль для налаштування інжекції залежностей з Guice.

   mvn clean install
